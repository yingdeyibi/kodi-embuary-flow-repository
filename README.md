# Embuary Flow 插件源

本仓库仅分发 Kodi 插件包、索引和校验文件。开发仓库保持私有；插件 ZIP 包含运行所需的 Python/XML 文件。

安装仓库插件：[repository.embuary.flow-0.1.1.zip](repository.embuary.flow/repository.embuary.flow-0.1.1.zip)。
在 Kodi 中从 ZIP 安装仓库后，从本仓库选择 Flow 安装助手、Flow Helper 或 Flow 皮肤。第三方配套补丁由安装助手提供，不以第三方原插件 ID 发布更新。

当前安装助手 0.1.3 已通过本地核验，尚未完成该版本设备安装验收。

许可证：GPL-2.0-or-later；各内嵌插件保留自身许可证。

本项目使用 OpenAI Codex 辅助开发，部分或全部代码由 Codex 参与编写与维护。
